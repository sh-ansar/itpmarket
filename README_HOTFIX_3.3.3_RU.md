# ITP Market Intelligence 3.3.3 — Interface System

## Реализовано

- видимые подписи верхней навигации;
- раздел «Пользователи» переименован в «Сотрудники»;
- светлая, тёмная и системная тема без вспышки при загрузке;
- быстрый анимированный переключатель солнце/луна и сохранение темы в профиле;
- контекстная помощь для каждого раздела клиентской панели;
- закрытие профиля, мобильной навигации, модальных окон и помощи кликом снаружи или клавишей Esc;
- централизованная локализация RU / KZ / EN клиентской и платформенной панелей;
- локализованные страницы входа, первичной настройки и восстановления доступа;
- автоматический перевод динамически создаваемых таблиц, карточек, статусов и диалогов;
- адаптивная навигация и поддержка prefers-reduced-motion.

## Установка поверх 3.3.2

1. Остановить приложение.
2. Распаковать Hotfix в корень проекта с заменой файлов.
3. Запустить `APPLY_3_3_3_HOTFIX.bat`.
4. Запустить `START_SERVER.bat` или `START.bat`.
5. Выполнить `Ctrl + F5`.

Сборщики Ozon/Kaspi, matching, цены и история операций не изменяются. Сырые технические строки в журналах сборщиков сохраняются в исходном виде.
