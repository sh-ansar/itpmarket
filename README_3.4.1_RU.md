# Spyon 3.4.1

Hotfix устанавливается поверх 3.4.0.

Исправлено:
- планшетная и мобильная навигация;
- единая ширина верхней шапки, заголовка раздела и рабочей области;
- светлые SVG в тёмной теме;
- читаемость карточек контроля качества в тёмной теме;
- единая типографика KPI главной страницы;
- адаптив для dashboard, таблиц, операций, сотрудников, расписаний, модальных окон и drawer;
- дополнительный adaptive pass для публичного сайта и системной платформенной панели.

Расписание:
- Однократно — дата + время, без повторения;
- Ежедневно — время;
- По дням недели — Пн..Вс + время;
- Через интервал — 1 / 3 / 6 / 12 / 24 часа;
- существующее расписание можно изменить;
- дни недели и ближайший запуск видны прямо в карточке;
- однократное расписание автоматически отключается после постановки операции в очередь.

Установка:
1. STOP.bat
2. Распаковать hotfix в корень проекта с заменой файлов.
3. APPLY_3_4_1_HOTFIX.bat
4. SELF_TEST_3_4_1.bat
5. START_SERVER.bat
6. Ctrl+F5

Рекомендуемые проверки:
- 1440 / 1920 px desktop;
- 1024 px tablet landscape;
- 768 px tablet portrait;
- 430 / 390 / 375 px phone.
