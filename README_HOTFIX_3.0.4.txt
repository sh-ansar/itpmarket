ITP MARKET INTELLIGENCE 3.0.4 HOTFIX

INSTALLATION
1. Stop the application with STOP.bat.
2. Extract this archive into the project root and replace existing files.
3. Run START.bat.
4. For LAN access, run ALLOW_LAN_ACCESS.bat once as Administrator.
5. While the server is running, use CHECK_LAN_ACCESS.bat to see valid Wi-Fi/LAN URLs.
