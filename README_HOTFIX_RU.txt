SPYON 3.4.14 - установка

1. Распакуйте папку SPYON_HOTFIX_3_4_14 внутрь корня проекта, рядом с app.py.
2. Запустите APPLY_HOTFIX.bat.
3. После успешной установки из корня проекта запустите SELF_TEST_HOTFIX_3_4_14.bat.
4. Если тест завершился сообщением SELF TEST 3.4.14: OK, запустите START.bat.

Установщик проверяет SHA-256 всех файлов, останавливает Spyon и создаёт резервную копию:
backups\hotfix_3_4_14_YYYYMMDD_HHMMSS

Для отмены последней установки запустите ROLLBACK_LAST_HOTFIX.bat.

В GitHub установщик ничего не отправляет.
