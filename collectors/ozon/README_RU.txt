OZON COLLECTOR 3.0.0
====================

Что изменилось
--------------
Это новая чистая сборка. Она больше не хранит каждый запуск как отдельный набор
несвязанных JSON-файлов. Основой стал постоянный SQLite-реестр:

  data/ozon_registry.db

В нём сохраняются:
- article и постоянная ссылка карточки;
- дата первого и последнего обнаружения;
- характеристики шины;
- текущие предложения продавцов;
- история цен;
- очередь незавершённых задач;
- история запусков.

Рабочая схема
-------------
1. DISCOVER быстро проходит страницы каталога и сохраняет ссылки.
2. ENRICH получает полные характеристики только для новых и неполных товаров.
3. REFRESH PRICES обновляет цены по уже известным article.
4. REFRESH STALE повторно получает характеристики старше заданного срока.
5. RETRY FAILED повторяет только ошибки и блокировки.
6. FULL SYNC объединяет discovery и последующую обработку.

Первый запуск
-------------
1. Распаковать архив в новую папку.
2. Изменить START_URL.txt при необходимости.
3. Оставить EXPECTED_SELLER.txt пустым для анализа рынка.
4. Запустить 0_SETUP.bat.
5. Запустить 1_OPEN_VPN_BROWSER.bat.
6. Включить Urban VPN -> Russia и дождаться карточек с ценами.
7. Запустить 2_DISCOVER_PRODUCTS.bat.
8. Запустить 3_ENRICH_NEW_PRODUCTS.bat.

После первого наполнения
------------------------
Ежедневное обновление:
  2_DISCOVER_PRODUCTS.bat
  4_REFRESH_PRICES.bat

Полный автоматический цикл:
  7_FULL_SYNC.bat

Проверка устойчивости:
  8_STRESS_TEST_100.bat

Восстановление после ошибок:
  6_RETRY_FAILED.bat

Файлы результата
----------------
data/ozon_registry.db       постоянная база
reports/index.html          локальный dashboard
exports/unityre_current.csv текущий экспорт для Unityre
exports/unityre_current.json
runs/<run_id>/summary.json  итог конкретного запуска
runs/<run_id>/traces.jsonl  диагностический журнал
raw/<article>/              первый сохранённый сырой ответ карточки

Стабильность
------------
- одна вкладка Chrome;
- запись checkpoint в SQLite после каждого товара;
- случайная задержка между карточками;
- техническая пауза после каждых 50 товаров;
- circuit breaker после нескольких блокировок подряд;
- уже успешные карточки не теряются при закрытии консоли;
- повторный проход обрабатывает только нужные позиции.

Важно
-----
Ozon использует RUB, Kaspi — KZT. В текущей версии цены не конвертируются.
Курс и логистику следует добавлять на уровне общего аналитического модуля,
а не внутри сборщика Ozon.
