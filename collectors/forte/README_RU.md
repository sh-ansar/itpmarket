# Forte Market Collector

Интеграция собирает публичный каталог продавца Forte Market, точные предложения продавцов внутри той же карточки и историю цен. Секретные ключи не сохраняются и для аналитического контура не требуются.

## Настройка

В разделе «Настройки → Forte Market Collector» укажите:

- `Seller name` — отображаемое имя своего продавца;
- `Merchant ID` — идентификатор из ссылки `/merchant-products/<id>` или кабинета продавца;
- `City ID` — регион витрины, по умолчанию `KZ`;
- `Category ID` — необязательное ограничение категории;
- лимит, паузу и тайм-аут для безопасного тестового запуска.

После сохранения используйте «Сбор каталога», «Актуализация цен» или «Полная синхронизация». Сборщик повторяет временные сетевые ошибки, ограничивает размер страницы, сохраняет состояние запуска и не деактивирует товары других продавцов.

## Проверка соединения

```powershell
python collectors/forte/forte_collector.py probe --category-id 171884c9-4db0-11e7-abc4-708bcda3b266
```

Проверка не изменяет базу. Для ограниченного запуска задайте в интерфейсе `Test limit`, например `10`.

## Границы интеграции

Это инструмент рыночной аналитики публичной витрины. Создание и редактирование товаров, остатки, заказы и взаиморасчёты относятся к закрытому Seller API и требуют отдельного согласованного подключения Forte Business.
