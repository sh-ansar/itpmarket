ITP Market Intelligence 3.2.1 — UI Hotfix

Изменения:
- блок page-context удалён;
- настройки убраны из основной навигации и остаются в меню пользователя;
- верхняя навигация состоит только из чёрных SVG-иконок;
- при наведении на иконку выводится название раздела;
- навигационные SVG вынесены в static/icons/navigation;
- всем select добавлена стандартная стрелка вниз;
- по всем страницам унифицированы размеры 12/16, 14/20 и 16/24;
- основная гарнитура — Inter;
- избыточная жирность таблиц, карточек, кнопок и подписей снижена;
- backend, matching, базы и сборщики не изменялись.

Важно:
Файлы шрифта Inter не включены. Чтобы на каждом клиентском компьютере
гарантированно отображался Inter, установите Inter в Windows либо позднее
подключите его через корпоративный CDN.
