# ITP Market Intelligence 3.4.0 — Public Product

Версия устанавливается поверх 3.3.3 / 3.3.3.1 и не меняет рабочие сборщики, базы и браузерные профили.

## Реализовано
- новый динамический публичный лендинг без названий банков, торговых площадок и продавцов;
- публичное позиционирование через автоматизацию онлайн-продаж, рыночную аналитику, ассортимент и рекомендации;
- RU / KZ / EN для публичного сайта и регистрации;
- регистрация компании по бизнес-задачам, а не по названиям интеграций;
- фиксация согласия с политикой и условиями;
- Privacy Policy, Terms of Use, Cookies, Personal Data Consent и управляемая Public Offer;
- платформенная панель: клиенты, состояние интеграций, ошибки, расписания, техническая карточка клиента;
- редактирование юридических реквизитов и публичной оферты из `/platform`;
- светлые SVG-иконки навигации в тёмной теме.

## Юридическая часть
До публичного промышленного запуска заполните в `/platform` юридическое наименование оператора, регистрационный номер, адрес, юридический email и юрисдикцию.
Публичная оферта выключена по умолчанию и не включится без обязательных реквизитов, стоимости и порядка оплаты.

## Установка
1. `STOP.bat`
2. Распаковать Hotfix в корень с заменой файлов.
3. `APPLY_3_4_0_MIGRATION.bat`
4. `START_SERVER.bat` или `START.bat`
5. `Ctrl + F5`

## Git
`PREPARE_REPO_FOR_GIT_3_4.ps1` удаляет машинно-зависимые файлы только из индекса Git. Локальные базы, Chrome-профили, runtime и output физически не удаляются.
