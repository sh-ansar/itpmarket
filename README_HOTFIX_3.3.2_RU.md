# ITP Market Intelligence 3.3.2 — Ozon Market Search

Исправлена причина отсутствия рыночных цен Ozon: общие категории возвращали
только ограниченную часть каталога, поэтому системе не из чего было строить
сопоставления.

## Новая операция

`Ozon → Поиск рыночных предложений`

Для каждой клиентской позиции выполняются последовательные поиски:

1. бренд + артикул производителя;
2. бренд + модель + размер;
3. бренд + размер — только если точный или сильный вариант не найден.

## Уровни сопоставления

- EXACT — совпали артикул производителя либо бренд, модель и размер;
- STRONG — совпали бренд и размер, модель имеет высокую близость;
- COMPARABLE — совпали бренд и размер, но модель или индексы отличаются;
- REJECTED — другой бренд, размер, тип товара, сезонность или шипованность.

EXACT и STRONG считаются точным рынком. COMPARABLE отображается как
сопоставимый рынок бренда и размера и не называется точным товаром.

Статус `1 / 1` при отсутствии конкурентов удалён: позиция рассчитывается
только при наличии хотя бы одного чужого предложения.

## Установка

1. `STOP.bat`
2. распаковать архив с заменой файлов;
3. `APPLY_3_3_2_HOTFIX.bat`;
4. `START_SERVER.bat` или `START.bat`;
5. Ctrl+F5;
6. запустить `Ozon → Поиск рыночных предложений`.

Первый проход обрабатывает 30 клиентских товаров. Для оставшихся позиций
операцию можно запустить повторно: очередь начинает с товаров без поиска и
без найденного рынка.
